# Flutter Networking

A collection of examples focused on fetching data from the web, handling REST APIs, and JSON serialization.

## Implementation List

### 1. [Basic HTTP/Dio]

- **Description:** Simple GET and POST requests to public REST APIs.
- **Key Skills:** Headers, status codes, async/await, error handling.
- **Status:** Done

### 2. [JSON Parsing]

- **Description:** Converting raw JSON data into strongly typed Dart objects.
- **Key Skills:** Factory constructors, manually vs auto-generated models.
- **Status:** Done
