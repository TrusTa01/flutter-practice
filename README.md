# Flutter Navigation

A collection of examples demonstrating routing systems and navigation patterns in Flutter.

## Implementation List

### 1. imperative - topic/navigation/imperative

- **Description:** Basic navigation setup using string-based route names
- **Key Skills:** Route generator, arguments passing, context-based navigation
- **Status:** Done

### 2. declarative (go_router) - topic/navigation/declarative

- **Description:** Implementing declarative routing with deep linking and nested shells
- **Key Skills:** ShellRoute, redirect logic, URL patterns, state-based routing
- **Status:** Done
